MANVA (formerly "Auto") - Android app bundle
- release/Manva.apk   : installable debug APK (package com.auto.app, so it updates the old Auto app in place)
- release/logo/       : logo, 1024 icon and adaptive-icon foreground
- app/, core/ ...     : full source (Kotlin / Jetpack Compose / Media3). Start with HANDOVER.md
Build: push branch `redesign` and run the GitHub "Build APK" workflow (the sandbox has no Android SDK).

# Voice Studio

A free web app that turns a script into natural, conversational narration using Google's Gemini voices. It installs to a phone's home screen like an app. The voices are made on Google's servers, so it is fast and works on any phone.

## How to use
1. One-time setup: tap **Get my free key**, sign in with Google, tap **Create API key**, copy it, paste it in the app and tap **Save key**.
2. Paste or type your script, or add a file (.txt, .docx, .pdf, .epub, .srt and more).
3. For a two-person conversation, write lines like `Ravi: Hello!` and `Priya: Hi!`. The app gives each person their own voice.
4. Tap **Make narration**, then play or download the WAV file.

## Notes
- Free use has daily limits set by Google. If the limit is reached, the app says so; try again later.
- On the free tier, Google may use the text and audio to improve its products.
- The key is stored only on the phone.
